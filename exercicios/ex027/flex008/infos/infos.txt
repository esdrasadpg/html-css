1. O order serve para ordenar os elementos de um contêiner. 

2. Todo elemento dentro de um contêiner, por padrão tem order: 0. Se caso você usar o order e alterar, a ordem de prioridade é: negativos primeiro (como -1), depois 0, depois positivos (como 1), obviamente em ordem crescente.

3. Caso um ou mais elementos tenham order 0, o que vier primeiro no código aparece primeiro.
